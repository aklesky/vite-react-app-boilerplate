# vite-react-app-boilerplate

Template for new React apps built with Vite and deployed to Cloudflare Workers, set up with the [@aklesky/node-presets](https://github.com/aklesky/node-workspace#readme) collection.

## Stack

| Tool                                                         | Preset                                                                                                                              |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| React 19 with the React Compiler, Vite 8, Cloudflare Workers | [@aklesky/react-presets](https://www.npmjs.com/package/@aklesky/react-presets) (`worker.js`)                                        |
| Tailwind CSS 4 with forms and typography                     | [@aklesky/tailwindcss-presets](https://www.npmjs.com/package/@aklesky/tailwindcss-presets)                                          |
| TypeScript 7 (`tsc`) and TypeScript 6 (editors)              | [@aklesky/typescript-presets](https://www.npmjs.com/package/@aklesky/typescript-presets) and `tsconfig/jsx.json` from react-presets |
| oxlint with the React rules, oxfmt                           | [@aklesky/oxc-presets](https://www.npmjs.com/package/@aklesky/oxc-presets)                                                          |
| Vitest with coverage and an HTML report                      | [@aklesky/vitest-presets](https://www.npmjs.com/package/@aklesky/vitest-presets)                                                    |

Node.js 24.22.1 and pnpm 12.15.0 are pinned in `package.json`.

## Layout

- `index.html` and `wrangler.jsonc` in the project root
- `src/` for the React app, `worker/` for the Worker that answers `/api/*`
- `public/` for static files
- tests next to the code they test: `src/app/app.test.tsx` and `worker/index.test.ts`

## Styling

Tailwind CSS 4 comes through [@aklesky/tailwindcss-presets](https://www.npmjs.com/package/@aklesky/tailwindcss-presets), wired in at two places:

- `vite.config.ts` adds the Tailwind CSS Vite plugin with `withTailwind()` from `@aklesky/tailwindcss-presets/vite.js`.
- `src/index.css` is the only stylesheet. It imports `tailwindcss` and `@aklesky/tailwindcss-presets/preset.css`, which loads the `@tailwindcss/forms` and `@tailwindcss/typography` plugins.

Components use utility classes only. The text block uses `prose prose-invert` from the typography plugin, and the name input is styled on top of the base styles of the forms plugin.

## Scripts

| Script           | Runs                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| `pnpm dev`       | the app and the Worker locally                                           |
| `pnpm build`     | type checks, then `vite build` to `dist/client` and `dist/<worker name>` |
| `pnpm typecheck` | `tsc` on the app, Worker and config files                                |
| `pnpm preview`   | the built app and Worker locally                                         |
| `pnpm deploy`    | builds and deploys with `wrangler deploy`                                |
| `pnpm test`      | Vitest, with the HTML report in `ui/`                                    |
| `pnpm lint`      | oxlint                                                                   |
| `pnpm format`    | oxfmt check; `pnpm exec oxfmt` formats                                   |
| `pnpm types`     | regenerates `worker-configuration.d.ts` after changing `wrangler.jsonc`  |

## TypeScript

The app, the Worker and the config files have separate configs, because DOM and Worker globals conflict:

- `tsconfig.app.json`: the React app, with JSX and the Vite client types
- `tsconfig.worker.json`: the Worker, with the types generated by `wrangler types`
- `tsconfig.node.json`: `vite.config.ts` and the other config files

Relative imports use the `.js` extension, for example `import { App } from './app/app.js'`.

## Dependencies

Renovate (`renovate.json`) checks for updates before 9am on Mondays:

- Minor and patch updates come in one PR, 7 days after their release. The `@aklesky/*` presets come without the wait.
- Each major gets its own PR after you approve it on the Dependency Dashboard.
- `@types/node` stays on 24, matching the Node.js version in `devEngines`.
- The lockfile is refreshed on the first day of each month.

`pnpm-workspace.yaml` turns off the install scripts of `core-js`, `esbuild`, `sharp` and `workerd` (`allowBuilds`) and lets `@aklesky/*` install without pnpm's minimum release age.
